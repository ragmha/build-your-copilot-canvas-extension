# Code of Conduct

This project is a learning space. Participate with empathy, patience, and
respect.

## Expected behavior

- Give constructive, specific feedback.
- Welcome learners with different backgrounds and experience levels.
- Keep discussions focused on the exercise and its improvement.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption,
or publishing another person's private information are not acceptable.

Project maintainers may edit or remove contributions that violate these
expectations and may restrict participation when necessary.

Report conduct concerns privately to the repository owner through their GitHub
profile. Do not include sensitive personal information in a public issue.
